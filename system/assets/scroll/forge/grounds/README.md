# Scroll Forge — Ground Tiles

Parchment ground tiles are curated PD scans (see `../ATTRIBUTION.md`). Until a
family declares `ornament.ground.tile` in `families.json`, parchment families
keep the procedural vellum. `ivory` / `white` grounds are flat CSS + suppressed
mottle/deckle — they never load a tile.

Sourcing happens in the Task 10 curated-asset session (explicit user approval of
exact URLs + licenses before any download). Every scan added here MUST get an
entry in `system/assets/scroll/forge/ATTRIBUTION.md` (library, shelfmark or
identifier, license, source URL) — `tests/scroll/test_curated_assets.php`
enforces this.
